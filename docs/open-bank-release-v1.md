# Реальные записи как основная база · Beta224

2136 событий (163219063 байта) и 378 фонов локаций (834405307 байт).
969 неоднозначных/проблемных записей исключены; review удалён по просьбе
пользователя, state-метки предотвращают повторную загрузку исключённого.

События до 8 с по спектральной активности; короткие не растянуты. Фоны целиком.
AAC128k/44,1кГц/stereo. Ориентир событий −22 LUFS (медиана 151 файла прежней базы
−21,65), сцен −26 LUFS из Loudness.kt; потолок новых файлов −3 dBTP. Мягкая
компрессия применяется при проблемной динамике, без жёсткого лимитера;
не укладывающиеся без чрезмерного ограничения исключены. Короткие импульсы
выравниваются по пику, поскольку R128 короче 400 мс не определён.

Результаты: ../listening/open-bank относительно корня репозитория.
GitHub-комплект: github-release, два prerelease open-sounds-events-v1 и
open-sounds-scenes-v1, 22+4 ZIP по сто файлов, manifest.json, sounds.db,
CREDITS.md. Манифест содержит архивный URL/размер/SHA256 и SHA256 каждого клипа.
Клиент проверяет архив, извлекает только известные плоские имена и проверяет
каждый файл; готовое не скачивается повторно. Частично извлечённый проверенный
архив сохраняется для продолжения. Тысячи отдельных GitHub-вложений не нужны.
Источники/лицензии публикуются отдельно, в приложении есть явная ссылка.

Приоритет событий: реальные → старая база (когда включена) → генератор.
Для начала подключены 167 консервативных связей видов с реальными записями.
Остальные не подставляются по приблизительному совпадению. Сопоставление с
948 опубликованными видами: 310 прямых кандидатов, 159 частичных, 479 без
кандидата. Это сравнение описаний, не слуховая проверка. Детский плач не
подменяет взрослые рыдания; стук зубов не подменяет скрежет.

Фон локаций: новая база → генератор; музыка настроения — отдельная функция.
Готовые записи берутся до проверки наличия генератора, его отсутствие не
блокирует копирование доступных записей.

Независимые настройки: sound_bank_real_events (default false),
sound_bank_real_scenes (false), sound_bank (прежнее значение, default true).
Новые базы требуют включения, тумблер запускает загрузку. Выключенная база
не скачивается и не используется. Удаление сначала отключает базу, затем
удаляет её файлы и кэш архивов. Старая база в sound-bank; новые отдельно в
open-sound-bank/events и scenes. Источники входят в рецепт кэша книги,
поэтому повторная подготовка не берёт несовместимые старые копии.

Локально прошли 7 Python-тестов и 11 JVM-тестов. Новый Android-клиент
скомпилирован против Android API. На телефон скопированы 2514 записей,
все SHA256 проверены. APK собирается только на GitHub. Слуховой проверки
всех записей не было.
