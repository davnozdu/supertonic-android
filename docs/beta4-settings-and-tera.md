# Share, вставка и короткие фразы Tera

## Общие настройки чтения

Проверка кода: QuickReadActivity вставляет буфер обмена в поле и передаёт его
через ACTION_SEND MainActivity. Прямой ввод, ссылки и браузер Share запускают
PlaybackActivity / PlaybackService. В этом общем пути применяются LLM,
MultiVoiceSettings, ForeignTts и BackgroundMusic.

На установленной Beta 4.7 выполнен беззвучный реальный ACTION_SEND с локальной
синтетической HTML-статьёй, 1418 знаков после извлечения. Настройки пользователя
сохранены: AUTO / Ollama, мультиголос включён, музыка включена, 7%.

- LLM: provider=ollama, 10/10 фрагментов подготовлены; три роли в проверенной
  разметке. Первые два фрагмента использовали автономный резерв по дедлайну
  1500 мс; последующие подготовленные фрагменты дошли в синтез.
- Tera: автор ru_m5, мужские реплики ru_m1, женские ru_f2. Логи маршрутизации
  подтверждают выбор этих файлов стиля в реальном PlaybackService.
- Английский и чешский: com.google.android.tts, lang=en и cs; получен PCM
  продолжительностью 2913 и 2557 мс соответственно.
- Музыка: MediaPlayer MyTTS в состоянии PLAYING, loop=1, renderer paused=0,
  левая/правая громкость 0.07. Трек ready:lamplight_and_paper.

Это проверка потока и состояний воспроизведения, не субъективная оценка звука.
Вход из буфера обмена проверен по коду; отдельный запуск через поле требует
остановленного пользовательского чтения.

## Остаточное растягивание гласных Tera

Пользователь слышит его редко, только у Tera, конкретная фраза неизвестна.
С установленного пакета скопирован только duration_predictor.onnx и style_dp
голоса ru_m5; синтетические строки проверены ONNX Runtime на компьютере.
Текст книги не копировался и в облако не отправлялся.

При speed=1 и штатном делителе 1.05 предсказатель даёт:

| Текст | Длительность, с |
|---|---:|
| Ну, | 1.028 |
| Пока! | 1.041 |
| Хорошо, | 1.054 |
| Понятно, | 1.062 |
| Хорошо, он вернулся домой. | 1.914 |
| Понятно, он вернулся домой. | 1.855 |

Почти одинаковая длительность коротких реплик подтверждает риск при их
изолированном синтезе, но сама по себе не доказывает длительность звучащей
гласной: в итоговом PCM есть естественная тишина и интонация.

Beta 4.8 расширяет прежнее объединение с соседним текстом с двух до трёх
гласных, с восьми до двенадцати букв. Исходные знаки и ударения сохраняются.
Звук не обрезается, скорость длинных фраз и другие движки не меняются.
Одиночную реплику без контекста объединить невозможно; полное исчезновение
дефекта не обещается. Естественность должен подтвердить пользователь.

Локально прошли 21 JVM-тест пунктуации, подготовки Tera и пробелов: отдельные
короткие реплики, сохранение текста/явных ударений, обычные границы запятых
и предложений, учёт существующей тишины.
