# Ударения: словари голосуют, LLM — арбитр (5.0.4-beta10, 12 октября 2026)

Схема выбрана пользователем по его проверкам и подтверждена на наших эталонах. Одинакова для всех цепочек.

## Как работает

1. **Два мнения на каждое многосложное слово**:
   - словарь RUAccent — `russian_accents_full.sacc` (3,26 млн форм по Зализняку, 179 МБ, `no_backup/stress-judge/`,
     скачивается сам один раз по безлимитной сети, SHA-256 проверяется). Омографы RUAccent из него не берутся;
   - Silero Stress (BERT для своих омографов, акцентор для незнакомых слов) + словарь имён + импортированный словарь.
2. **Совпали** — ударение окончательное, даже если LLM поставила другое.
3. **Разошлись**, а также **любой омограф RUAccent** (`assets/ruaccent_omographs.tsv.gz`, 19 732 слова,
   `tools/ruaccent/build_omographs.py`) — вопрос арбитру: предложение, предыдущее предложение, два варианта.
   Каждый вопрос задаётся дважды в разном порядке вариантов; решение принимается, только если оба ответа выбрали
   один и тот же вариант. Куски по 12, до 96 вопросов на пакет.
4. **Знает только один словарь** — его ударение. **Не знает никто** — ударение LLM.
5. **Арбитр противоречит себе / недоступен** — ударение LLM, если оно одно из двух; для имени — словарь имён;
   иначе RUAccent (при расхождении) или Silero (для омографа).

| Цепочка | Арбитр | Без арбитра |
|---|---|---|
| Облако (Ollama / Gemini / DeepSeek) | тот же провайдер (verifier можно переопределить в пробе) | правило п. 5 |
| Локальная Gemma (GPU или NPU) | сама Gemma, `LlmProviders.verifyStressLocal` | правило п. 5 |
| Без LLM / резерв «словарь» | — | RUAccent при расхождении, Silero для омографа |

- Слова с ё, явные метки книги/лексикона (`+`, U+0301) в голосовании не участвуют. ё восстанавливают LLM,
  словарь имён, `YoRestore` (безопасная таблица Silero) — до голосования в пути без LLM и Gemma, после — в облаке
  (`YoRestore` снимает метку с ё-слова).
- Пока словарь RUAccent не скачан, вторым мнением служит ударение LLM (как в прежней схеме).
  Если Silero выключен («Локальные ударения и ё по контексту») — его место занимает ударение LLM; без LLM разметки нет.
- Код: `llm/StressCheck.kt` (чистое ядро, `plan` / `items` / `resolve`), `local/RussianStressVote.kt` (Android),
  `LlmPreparation.stressVote`, `TextNormalizer` (путь без LLM), `StressProbe` (провайдер `OFFLINE` = тот же путь).

## Замеры

Симуляция на компьютере (`tools/stress_tests`, ответы Silero 1.5 и RUAccent, арбитр DeepSeek v4.1 Flash, Ollama):

| Вариант | Трудные (71) | «Идиот», гл. 1 (41) |
|---|---|---|
| Прежняя схема (LLM ставит, Silero проверяет), beta21 на телефоне | 67 | 39 |
| **Словарь RUAccent + Silero → арбитр LLM** | **70** | **40** |
| RUAccent turbo3 (нейросеть омографов 343 МБ) + Silero → арбитр | 65 | 39 |
| Без LLM: RUAccent при споре, Silero для омографа | 61 | 37 |
| Без LLM: Silero при споре | 61 | 36 |

turbo3 хуже, потому что согласованная ошибка двух систем на омографе (о́рган, хлопо́к) не доходит до арбитра.
При противоречии арбитра лучше всего метка LLM (70/71) против RUAccent / Silero (69/71).
