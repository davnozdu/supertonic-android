# Умная книга (5.0.6-beta1/beta2)

Кнопки «Ранее в книге», «Эта глава», «Чем закончится» в панели быстрого чтения (уведомление MyTTS).

## Как MyTTS знает книгу и место

Читалка (Moon+) не сообщает книгу. Движок в `onSynthesizeText` передаёт текст, который озвучивается сейчас,
в `SmartMatcher` (отдельный поток). Отпечатки предложений (`BookFingerprint`) ищутся в `SmartLibrary`
(`no_backup/smart_books.db`, `prints: hash → книга, номер абзаца`). Новая книга — после двух совпадений подряд,
внутри книги — одно. Последнее место пишется в prefs `smart_book` только при смене книги/раздела и не чаще
раза в 2 минуты.

Источники текста:
- **Подготовка книги с галочкой «Умная книга»** (экран книг): в `.mytts-book` добавляется блок `smart`
  (текст по разделам + краткое содержание каждого раздела). При импорте блок уходит в `SmartLibrary`
  (`no_backup/smart/<content_sha>.json.gz`), в `books.db` файл хранится без него; «Поделиться» возвращает его.
- **Папка с книгами** (меню → «Умная книга»): EPUB/FB2/FB2.ZIP по SAF, без LLM, `BookStructure.chapters`.
  Неизменённые файлы (размер и дата) не перечитываются; пересканирование при открытии экрана и при старте движка
  раз в 12 ч. Ключ книги — тот же `content_sha256`; подготовленная копия важнее копии из папки.

## Пересказ

Облако из настроек LLM (`BookPreparation.source`), **без размышления**, запросы строго по одному. Краткое
содержание раздела делается один раз и сохраняется (`summaries`), раздел длиннее 40 тыс. знаков — частями.
Итоговый ответ пишется с ударениями (U+0301), ё и числами словами и читается движком как доверенный запрос
приложения (`voice_preview`): без LLM, ролей и музыки, голосом из MyTTS. Перед пересказом читалка ставится на паузу,
«Продолжить чтение» шлёт ей Play.

Правила промптов (`SmartPrompts`), проверены на «Идиоте» (Ollama deepseek-v4.1-flash, без размышления):
- **Без названия и автора.** С названием модель «пересказывала» по памяти: титульная страница (48 знаков) дала
  краткое содержание всей первой части с финалом → спойлер в «Ранее в книге».
- Разделы короче 800 знаков (титул, эпиграф) не отправляются: их текст и есть их содержание.
- Инструкции и требования к ударениям — после текста книги: перед текстом модель их забывала.
- Ответ принимается и простым текстом (Ollama Cloud не принимает формат ответа).

Замеры: «Эта глава» — 1 запрос, ~5 с; «Ранее в книге» с IX главы впервые — 7 запросов, 21 с; «Чем закончится»
впервые — 42 запроса, 121 с (все разделы), потом 1 запрос. Содержание без событий после места остановки,
финал верный; изредка грамматическая ошибка («ссору семья») или слово без ударения.

Не проверено на телефоне: распознавание места в Moon+/Readest, озвучка пересказа, папка SAF, подготовка с галочкой.
KOReader (путь к файлу через плагин) — позже.

## beta2

- Кнопка «Ранее в книге» прямо в уведомлении «быстрое чтение», когда книга узнана (вместо «Вставить» — в уведомлении
  помещаются три кнопки; «Вставить» остаётся в панели). Открывает панель и сразу запускает пересказ.
- Очистка: удаление книги убирает текст, краткие содержания, отпечатки (и общие с другими книгами), место чтения;
  изменённый файл в папке заменяет старую запись; сиротские файлы удаляются при обновлении папки; после удаления
  `VACUUM`. На экране «Умная книга» показано занятое место.

## beta3 · фоновый режим

- Подготовка и озвучка пересказа идут в `SmartRecapService` (foreground, mediaPlayback): панель можно закрыть,
  экран выключить. Уведомление «Умная книга» показывает этап («Краткое содержание разделов · 3/7», «Звучит
  пересказ»), кнопки «Стоп» и «Продолжить чтение» (снимает читалку с паузы). Служба сама завершается, когда
  пересказ не готовится и не звучит; соединение с движком TTS тогда закрывается.
- `SmartSpeech` — один на приложение (не принадлежит экрану).

## beta4

- Панель: блок «Умная книга» наверху; если книга не узнана — выбор книги и главы вручную (SmartMatcher.choose).
  На телефоне после установки beta3 книга не была узнана, потому что чтения ещё не было (книга узнаётся только по
  тексту, который присылает читалка).
- Папка: интервал «Вручную / 1 / 3 / 6 / 12 / 24 ч» (по умолчанию 6) — проверяется только во время чтения, без
  будильников; «Искать новую книгу сразу» — незнакомая книга (6 текстов подряд без совпадений) запускает проверку один
  раз за сеанс чтения (сеанс — до перерыва 10 мин). Проверка без изменений — только список файлов SAF.
- Провайдер APInex (OpenAI-совместимый, `https://api.apinex.bond/v1`, по умолчанию `free/deepseek-v4.1-flash`, ключ
  зашифрован). Бесплатный режим — 5 запросов/мин: `ApinexApi.acquire` выдерживает интервал. Проба на «Идиоте»:
  3–4 с на запрос, но ударений почти нет и они часто неверные (Швейцарии́, Ганя́), фактическая ошибка («подал отцу»);
  заметно хуже DeepSeek через Ollama. Политика хранения данных APInex не опубликована.

## beta5

- APInex: лимит бесплатного плана **15** запросов/мин (`/v1/balance` → `"rpm": 15, "rpm_plan": "free"`, заголовки
  `x-ratelimit-limit: 15`; «5 RPM» на странице модели устарело). Лимит берётся из `/v1/balance` раз в час.
- Краткие содержания пакетами: несколько глав в одном запросе до 120 тыс. знаков (`SmartPrompts.summarize/several`),
  ответ `{"summaries":[{"id","summary"}]}`; пропущенная моделью глава спрашивается отдельно, сбой пакета — тоже.
  «Идиот», всё (ending): APInex 16 запросов вместо 42 (154 с, два запроса по 33–39 с); Ollama «Ранее» с части II гл. VIII:
  8 запросов, 43 с (раньше ~22). Ollama без параметра формата JSON-пакет вернула корректно.

## beta19 · роли без LLM (мультиголос)

- Замер на «Идиоте» (100 абзацев диалогов, эталон — разметка реплик книги, DeepSeek с размышлением): облачная
  разметка ролей (DeepSeek 4.1 Flash, без размышления) 99,3% слов реплик верно, 0,5% неверный пол. Запасной
  `LocalSpeakers` (пока LLM не ответила, «не ждать LLM») — 77,3% по абзацам, 74,9% по предложениям, 19% реплик читал автор.
- Причина: тире внутри реплики («…и вам одной, — не знаю») считалось началом ремарки. Теперь ремарка — только если за
  тире идёт глагол прошедшего времени / деепричастие / он, она / имя персонажа книги: по абзацам 88,6%, автор 4,1%.
- KOReader: абзац, который LLM не обработала, размечается `LocalSpeakers` целиком (KoreaderAhead), предложение
  вырезается из него — точность как у абзацев вместо 75%.
- Проверены и НЕ дали эффекта на этом наборе (не внедрены): пол по «я была/сама», память пола имён из ремарок,
  чередование по очереди реплик, различение мужчин по имени, обучение запасного алгоритма на ответах облака.

## beta20 · аудит (утечки, гонки, лишняя работа)

- KoreaderAhead: снятый из очереди LLM абзац больше не отправляется заново от имени приложения (`prepareResult(resubmit=false)`);
  предложение абзаца, который ещё у LLM, читается сразу словарями (голоса — по абзацу), без своего запроса и ожидания 1,5 с;
  абзац, на который LLM не ответила, спрашивается снова через 2 мин; новый список предложений заменяет старый (после перехода
  не синтезируется звук покинутого места).
- ReaderAudioAhead: ожидание места в кэше прекращается через 5 мин без воспроизведения (не просыпаться раз в секунду вечно).
- SmartBookProvider «prepare»: только из KOReader (org.koreader*), выполняется в фоне — перелистывание не ждёт.
- SmartSpeech: соединение с движком закрывается через минуту после конца речи (повтор из KOReader без службы), пауза > 15 мин
  останавливает пересказ.
- SmartMatcher: место чтения — по тексту без кратких содержаний (раньше на каждое предложение читались все summaries из БД).
- Плагин c0343df: «Закрыть»/«Продолжить чтение» останавливают опрос окна; на паузе опрос раз в 5 с; страница наперёд
  отправляется снова, если MyTTS был недоступен.

## beta21 · звук наперёд для KOReader снова находится

- Живой лог beta20: первый (prefetch) запрос плагина синтезировал заново 0,4–1,5 с, aheadBytes ≈ 25 МБ (≈ 4,7 мин из 5): лимит
  занят звуком уже прочитанных/покинутых предложений (или присланных плагином чуть иначе) — он не освобождался, новый не делался.
- KoreaderAhead помнит отправленные на звук предложения; всё, чего нет в новом списке плагина, сбрасывается
  (`ReaderAudioAhead.drop`: задача пропускается, звук перестаёт считаться «наперёд»). Звук наперёд ставится в очередь в своём
  потоке, а не за ожиданием LLM (до минут) — после перелистывания начинается сразу.
- SentenceAlign: при повторе слов в абзаце выбирается место с точным написанием (3/696 → 1/696 на «Идиоте»).
