# Дополнительные голосовые пакеты · Beta 224

## Shtorm

Папка пользователя `TeraWav/wav` содержит 12 голосовых референсов для **Shtorm PocketTTS RU**, а не стили Tera. Native Pocket читает MP3 непосредственно через dr_mp3 (`vendor/pockettts/PocketTTS.cpp/pocket_tts.cpp`, load_audio), без распаковки в постоянные WAV.

Подготовлены тем же `PocketVoicePrep`, что свой голос: исходный declip до sinc-resample, 24 кГц mono, high-pass 70 Гц, сокращение только длинных пауз, чистый речевой фрагмент 4–10 с, speech RMS −20 dBFS с запасом по пикам. MP3 96 кбит/с, 12 файлов = **1 161 180 байт** вместо примерно 18 МиБ исходников. Исходные WAV не изменены. Все MP3 повторно декодированы: конечные samples, длительность не менее 3 с, клиппинга нет. Это техническая проверка, не прослушивание результата синтеза.

Маркус: оценка исходного SNR ≈18.6 дБ, хуже остальных; шумоподавление не применялось. Остальные записи по эвристике не muffled/clipped. Для исходных референсов пользователь не приложил лицензию: не смешивать с CC0 sound bank и не присваивать им CC0.

Пакет `shtorm-extra-voices-v1`, bundled `shtorm_extra_voices.json` фиксирует размер/SHA каждого MP3. Выбор отсутствующего голоса или его preview скачивает только этот MP3. В автоматическое назначение ролей попадают только установленные голоса. Удаление голоса удаляет его MP3. 7 основных Kyutai references сохранены отдельно; импорт своего голоса не менялся.

## Silero

`ruvoice-pack-ru_voices` — format 2 / v5.5 с 22 speaker IDs (5 штатных +17 дополнительных). TorchScript mel проверен на компьютере для всех 22 IDs: конечные различные выходы. Backbone/head имеют поддерживаемый движком формат. Android-совместимость требует отдельного прогона после установки.

Это отдельная модель `silero_ru_voices`, root `silero-ru-voices`; существующие v5.6 и CIS не заменяются. Архив `silero-ru-voices-v1/ruvoice-pack-ru_voices.zip`, 80 141 313 байт, SHA-256 `122ae0196d0b50f7e6f0659dd7fa854309ae256fcfdaecc68d69771e5f87a43d`. Исходный pack.json и его сведения о CC BY-NC-SA 4.0 / источниках RUSLAN и Wikipedia сохранены, LICENSES.md приложен отдельно. Общие веса скачиваются при выборе модели; 22 маленьких speaker JSON создаются локально.
