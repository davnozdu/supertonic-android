# Beta227: подбор открытой базы звуков

Проблема: concepts в манифесте были построены из всего описания. Упоминание города в описании лягушек или трамвая делало их кандидатами обычной улицы. Соль книги выбирала любой из 12 результатов, включая слабые.

Изменения общего поиска:
- Основной тип сцены определяется по предмету заголовка записи. Теги описания уточняют, но не переопределяют его.
- Для постоянного фона минимум 30 секунд; копируется вся запись, существующее зацикливание сохранено.
- Пентхаус внутри и открытый балкон/карниз различаются; отдельные события после `|` не меняют локацию.
- Проезды транспорта, аплодисменты, синтетические Halloween-фоны и контактные записи турбин исключены из постоянного фона. Файлы не удаляются, система наложения событий не менялась.
- Отрицания («без дождя», «без транспорта», «без птиц») не превращаются в положительные признаки. Учитываются погода, день/ночь, явное отсутствие речи/музыки, крытый/открытый рынок; для исторической улицы без подходящей записи остаётся генерация. Дневное пение птиц не назначается ночному лесу.
- Выбор вариантов только среди кандидатов с лучшей оценкой, без случайного слабого 12-го результата.
- Исправлены ошибочные event kinds: компьютерный писк/задний ход грузовика, тиканье/таймер, пистолет/дробовик, взведение/спуск курка, игрушечная катушка и имитация свиньи. Добавлены точные соответствия для выстрела, тиканья, стула, бумаги, спички, выключателя, вздоха, раздвижной двери и безопасные синонимы.
- Приоритет событий уже был новая база → старая → генерация и сохранён. Сцены используют новую базу → генерацию.
- Recipe v2 для обоих каналов заставляет при повторной подготовке пересмотреть ранее принятые клипы. Самопроизвольно текущая книга не изменяется.

Проверка: закреплены метаданные всех 378 сцен и 2136 событий; 23 JVM-тест, включая полный каталог, прошёл. Android-клиент скомпилирован отдельно против Android API. Отчёт фактического Kotlin-поиска: `open-bank-match-audit.tsv`. Это аудит метаданных и подбора, не слуховое прослушивание всех записей; точность семантики любой произвольной книги не гарантируется.

Контрольные результаты: пентхаус → 0080 (закрытое окно, 242 с); наружный карниз → 0680/1438/1713 (81/407/117 с); горный ручей → 2754/2755/2756/3222; открытый рынок → 2728/2730/3378–3381. Фон музыки настроения остаётся отдельной функцией и может генерироваться.

Сборка также содержит Beta226: запрет фоновой музыки только для внутренней тестовой озвучки, внешние читалки сохраняют музыку. Экспериментальные offline-роли не включены: сначала нужно измерение.

Для проверки дополнительных кандидатов использован существующий отчёт `tools/sound_bank/compare_open_bank.py` (MiniLM) / `coverage_report.py`. Его предложения не становятся автоматическими соответствиями: в отчёте, например, swallow (глотнуть) ошибочно связан с ласточками, а pan_drop — с каплями в кастрюле. На телефон эта модель поиска не добавлялась.
