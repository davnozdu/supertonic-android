# Silero v5_6_ru и знаки препинания (5.0.5-beta1, 19 октября 2026)

## Модель

- `v5_6_ru` вышла 15 октября 2026 (snakers4/silero-models, models.yml): те же пять голосов
  (aidar, baya, kseniya, eugene, xenia), алфавит и id символов не изменились. Новое — эмфаза
  (`**слово**`) и восклицания. Лицензия прежняя: CC BY-NC-SA 4.0.
- Сигнатура `forward` выросла до 14 аргументов (`emphasis`). Официальный код v5.6 всегда передаёт
  `focus_mask` нулями: в v5.6 нулевая маска добавляет обученный эмбеддинг, `None` его пропускает и даёт
  другой звук (проверено: длительности и звук расходятся). В `pack.json` записано `"args": 14`;
  `SileroEngine` для такого пака передаёт нули и `emphasis = None`. Пак v5.5 / CIS — как раньше.
- Эмфазу не используем: в официальном коде она требует нескольких вызовов предикторов по окнам
  предложений (не один `forward`), а разметки `**слово**` у нас нет.
- Пак собирает `tools/export_silero_pack.py` (torch 2.14 + executorch 1.5.0, без кода ruvoice):
  `tts_mel.ptl` (модель без вокодера), `backbone.pte` (XNNPACK fp32, до 6000 кадров), `head.ptl`.
  Скрипт сверяет разрезанную модель с исходной: длительности побитно, звук 48/24 кГц < 1e-4,
  `.pte` < 1e-3. Байткод Lite v8; дополнительно `tts_mel.ptl` выполнен интерпретатором Lite из
  torch 2.1.0 (как `pytorch_android_lite:2.1.0` в приложении): длительности совпали, мел до 1.3e-5.
- Файл `ruvoice-pack-ru-v5_6.zip` (85 221 248 Б, SHA-256 `d79386e8…281fda`) в релизе
  `russian-resources-v1`, manifest.json дополнен. Папка на телефоне прежняя (`silero-v5_5_ru`),
  ID модели прежний: выбранные голоса и голоса книг сохраняются; новый SHA просит скачать v5.6.

## Тире, дефисы, скобки (замер на v5.6, кадр 12,5 мс)

| Вход | Что делает модель |
|---|---|
| `он – врач` | тире 6–9 кадров паузы, гласная перед ним тянется (`о` 16 кадров вместо 4) |
| `как-нибудь`, `кто-то`, `по-моему` | дефис 4–5 кадров внутри слова + растяжение — слово рвётся |
| `кт+ото` (склеено) | звучит слитно, на 0,1 с короче |
| `северо запад` (пробел) | обычная граница слов, 3–4 кадра, без растяжения |
| `( ) « » " /` | нет в алфавите; у нас — пробел, официальный код их просто выбрасывает |
| `:` `;` | ~23–24 кадра (~0,3 с) |
| `…` | ~30 кадров и тянет гласную перед ним |

С 5.0.5-beta1 `SileroText.dashes` (только Silero RU и CIS): отдельные тире `– — -` убираются;
частица через дефис склеивается со словом с сохранением ударения (`-то -либо -нибудь -ка -таки -де
-тка -с`, `кое- кой- по- во- в- из-`); прочие составные слова (`северо-запад`, `двух-трёх`) — через
пробел. Пробел перед знаком препинания после выброшенной кавычки/скобки убирается. Скобки и кавычки
по-прежнему без паузы. Tera/Kokoro/Shtorm не менялись.
