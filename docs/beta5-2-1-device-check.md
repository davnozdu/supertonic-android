# MyTTS 5.0 Beta 2.1: проверка на телефоне

4 октября 2026 года, OnePlus CPH2745 / Android 16. Установлен ARM64 APK
из публичного prerelease `v5.0.0-beta2.1`, versionCode 88, поверх прежнего приложения.
SHA-256 совпадает с digest ассета GitHub:
`2a28bbdf8e588be9dc6b2b01c6564f5aa89742f04bda5578af6a5f9701a06c2f`.

Проверки выполнены через закрытую SpeechDiagnosticsActivity на синтетическом
тексте. WAV-проверки не воспроизводят речь; тест очереди использует volume=0.
После тестов обе группы SharedPreferences совпали с резервными копиями до
диагностики. Настройка сохранения экрана при USB возвращена в исходное значение 0.

## Результаты

- Silero v5.5 + Ollama DeepSeek: автор `aidar` (speaker 0), женщина `kseniya`
  (2), мужчина `eugene` (3). Все три роли дошли до нативного синтезатора;
  разметка и правки LLM использованы, внутренний акцентор обойдён.
- Искусственный однократный сбой облачной разметки: локальная Gemma реально
  вызвана. В этой пробе она вернула неполный ответ, который отклонён валидатором;
  безопасный вариант — голос автора. Запланированный повторный облачный запрос
  восстановил все три роли примерно через 5,6 секунды после начала ожидания.
  При выдаче взят обновлённый результат, несмотря на старое значение future.
- Silero CIS + Gemini: автор `ru_roman` (43), женщина `ru_saida` (47),
  мужчина `ru_bogdan` (12); синтез всех ролей прошёл. Отдельно проверены все
  29 голосов пакета: каждый вернул непустой WAV без ошибки.
- Tera + Ollama: автор `ru_m5`, женщина `ru_f2`, мужчина `ru_m1`;
  полный путь через LLM и три стиля завершился успешно. Отдельная проба всех
  десяти стилей, включая английские образцы и шёпот, прошла на русском тексте.
- Контрольный диалог Silero CIS: active RMS отдельных фрагментов 3259–3404
  единиц PCM16 (разброс около 0,38 дБ), максимальный пик 27353, клиппинга нет.
  Границы фрагментов восстановлены по длительностям нативных кадров; тишина
  исключена порогом abs(sample)>100. Это измерение одного диалога, не рейтинг
  всех голосов по воспринимаемой громкости.
- Tera и Silero v5.5: автономные ё/ударения, переключатель ё, «По стенам»,
  сохранение границ «Не раз было», сброс кэша, пять WAV-проб и три тихих
  фразы в очереди прошли. Подготовленные в фоне фразы дали первые байты
  из кэша за 1 мс у Silero и 2–3 мс у Tera.
- Готовый PCM выдаётся при занятой блокировке модели: обе проверки прошли,
  измеренное ожидание кэшированного ответа — 0 мс.
- В логах диагностических прогонов не зарегистрированы ошибки интеграции
  или аварии AndroidRuntime. Лимит PCM-кэша — 268435456 байт (256 МиБ).

## Что эти проверки не доказывают

Это не длительное прослушивание книги в Moon+ Reader, не реальный обрыв сети
в метро и не проверка естественности всех голосов на слух. Ошибка облака
внесена только в запрос ролей. Неполная локальная разметка Gemma остаётся
допустимым случаем с переходом на автора; качество разметки локальной LLM
не стало гарантированным. Времена выдачи PCM из кэша не равны величине
слышимой паузы между фразами Android.
