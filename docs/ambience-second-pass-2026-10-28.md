# Звуки событий: второй проход и один клип на вид

5.0.6-beta73, code 317. Продолжение `ambience-events-2026-10-28.md`.

## Что было не так в beta72

- Клип делался на каждое событие, а не на вид: разметка привязывалась к виду, а генератор — нет. Книга с 39 моментами
  заказывала 39 клипов по 8 секунд.
- Всё, что не попадало в закрытый список из 70 видов, уходило в `other` — один общий клип на всю книгу, то есть
  иногда в сцене звучало не то, что описано.

## Что сделано

1. **Один клип на вид действия.** `EventIndex.Event` несёт `kind`, книга хранит `kinds: {вид: английское описание}`
   (в том же JSON разметки), клип называется `k_<вид>.m4a` и играет на всех местах этого вида. Книги, размеченные
   раньше, читаются по-старому: без `kind` клип берётся по `e<N>`.
2. **Второй проход.** После разметки все события, которые модель не смогла отнести к списку (`other` или без вида),
   уходят одним запросом на книгу: модель группирует описания по СМЫСЛУ действия.
   - группа из двух и более — новый вид, один клип на книгу;
   - одиночное действие может присоединиться к известному виду из списка (тогда нового клипа нет);
   - одиночное действие, которому места в списке нет, **отбрасывается** (в `dropped`), а не играет «что-то не то»:
     фон локации там всё равно звучит;
   - список известных видов передаётся в запросе, чтобы модель возвращала их ключи, а не придумывала синонимы.
3. Второй проход необязателен: если запрос не удался (нет сети, ошибка), неопознанные действия просто отбрасываются —
   подготовка книги не падает.

## Проверка (материал, не подгонка)

Тестовая книга «Граф Магнус» (38 144 знака, 108 абзацев, половина — примечания переводчика), deepseek-flash,
плотность «Часто», настоящий `SceneMarking` + второй проход:

| версия | моментов | видов (клипов) | отказов |
|---|---|---|---|
| beta71 (вид в разметке, клип на событие) | 23 | 13 → 39 клипов | 0 |
| beta72 (плотнее, клип всё ещё на событие) | 39 | 20 → 39 клипов | 0 |
| beta73 (второй проход + клип на вид) | 55 | 24 → 24 клипа | 2 |

Индекс находит 50 из 55 моментов: остальные — тот же вид дважды в одном высказывании (клип 8 с, повтор не играется).

Локальные проверки (10): привязка по виду, несколько действий в абзаце, пересказанная цитата, отказ действия без
цитаты, английские описания всех видов, русское описание не доходит до генератора, группа из двух описаний даёт
один новый вид и один запрос на книгу, одиночное неопознанное действие отбрасывается.

## Что осталось

- Проверка на телефоне (генерация клипов `k_*.m4a`, звучание) не выполнялась.
- Книги, подготовленные раньше, надо разметить заново: иначе у них останется старый набор событий и клипы `e<N>`.
