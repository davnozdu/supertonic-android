# Аудит подготовки и чтения — Beta 11

Проверены входящие запросы Android TTS, LLM-подготовка, валидатор, сохранение настроек, паузы Tera, скачивание Gemma и подписанная сборка GitHub.

## Исправления

| Проблема | Исправление |
|---|---|
| Нативное падение Gemma отключало Moon от TTS | В Beta 10 сохранены классы и методы LiteRT-LM, вызываемые JNI. В Beta 11 добавлена проверка настоящего R8 mapping перед подписью APK. |
| Остановка/смена очереди могла запускать резервный провайдер | Отмена учитывается перед вызовом, после ответа и при ошибке. Отменяются также активные фрагменты, удалённые из очереди после тайм-аута чтения. |
| Ошибка одного фрагмента задерживала весь пакет | Валидные фрагменты завершаются сразу; резервные провайдеры получают тот же контекст и заполняют только нерешённые результаты. |
| Слишком длинный запрос мог вытеснить полезную очередь, затем быть отклонён | Проверка длины перенесена перед вытеснением. QUEUE_FLUSH отменяет старую очередь даже для пропущенного текста. |
| На входящем Binder-потоке расшифровывались оба ключа | Быстрая проверка режима читает только обычные настройки. Проверка простоя тоже не расшифровывает ключи. |
| Переключатели визуально менялись, но не сохранялись | Ударения, пунктуация, размышления, приоритет облака, GPU и время выгрузки сохраняются сразу. |
| Отдельно стоящий символ ударения мог попасть в синтез | Такой ответ отклоняется; ранее указанное `+`-ударение сохраняется. Арифметический плюс защищён от удаления. |
| Сокращения и инициалы вызывали лишние паузы | Добавлена обработка распространённых сокращений и инициалов. Пробельное тире ` - ` даёт паузу; дефис внутри слова сохраняется. |
| На Android 7 скачивание обращалось к API NotificationChannel | Канал создаётся только с Android 8. Отмена проверяется также перед сохранением проверенного файла. |
| Ручная сборка могла использовать другую ветку и имя APK | Workflow использует запрошенный тег для checkout, имени APK и публикации. |

## Проверки

- 25 JUnit-тестов текста, контекстных ограничений, чисел, политики размышлений и пауз прошли локально без Android-сборки.
- Проверка JNI mapping принимает сохранённые имена и отклоняет переименованный класс или getter. В релизном CI она применяется к фактическому результату R8.
- `git diff --check` без ошибок. Полная компиляция Android и release unit tests выполняются на GitHub.
- На телефоне подтверждён настоящий ответ Gemini 3.1 Flash Lite: 1473 мс, запятые, «светло́», «стои́т», «за́мок/замо́к», неизменные числа 1001 и 1101. Словарная подстановка в этом тесте не использовалась.

## Проверка после возвращения пользователя

Следующую сборку устанавливать после возвращения пользователя. Повторить длинное чтение Moon, отмену и переключение режима, локальную Gemma E2B и выгрузку RAM. После исправления JNI локальная модель ещё возвращала исключение провайдера; успешную локальную расстановку ударений пока нельзя считать подтверждённой. При повторном подключении вернуть `stay_on_while_plugged_in` к исходному значению 0: телефон был отключён до завершения восстановления настройки.

Читалка может передавать только текущий фрагмент. Непереданные страницы недоступны TTS; при превышении ожидания 1,5 секунды чтение использует словарь. Валидатор проверяет сохранность текста и форму ударений, а смысловую правильность ударения оценивает модель. Поэтому результаты небольшого облачного теста не гарантируют отсутствие ошибок в любой книге.
