# Beta228: отдельный запрос локации при выборе из банка

Реальная подготовка «Карниза» на Beta227 показала: 17/18 фоновых файлов имеют правильный тип; l3_2 оказался уличным. Дополнительный акцент «a faint gust rattles the balcony door frame» добавлялся к base prompt через запятую; matcher ошибочно считал всю строку основной локацией и переключал penthouse на outdoor из-за balcony.

Job теперь отдельно хранит bankPrompt=location.sound. Все варианты одной локации ищутся только по постоянному фону; описание варианта с акцентом сохраняется для генератора. Scene recipe v3 заставляет повторную подготовку обновить ранее выбранные файлы. Метод создания настоящих jobs используется в регрессионном тесте: все три варианта пентхауса, включая балконную дверь, должны выбрать помещение. Плеер, наложение событий, музыка и настройки не менялись.

На Beta227 SHA-аудит текущего прогона: 18 scene files, 42 event files из новой базы, 99 из legacy; остальные файлы — музыка/переход главы, снимок делался во время подготовки. Первая запись лога «73 sounds taken from the bank» означает jobs, а не физические файлы: у события бывает несколько вариантов. Готовые 42 event files против30 в предыдущем прогоне подтверждают расширение нового банка; это не доказательство точности всех событий книги.
