# Форматы голосов Silero и Tera

Проверено 4 октября 2026 года. Перенос голосов между движками пока не реализован.

## Что уже доступно

Silero v5.5 выбирает встроенный голос числовым идентификатором `speaker`.
В пакете приложения JSON голоса содержит этот идентификатор. Пакет Silero CIS
использует свою модель и свои идентификаторы; совпадение номера не означает
совпадение тембра между пакетами.

Tera выбирает два отдельных массива NumPy, `style_ttl` и `style_dp`.
Для опубликованных стилей их формы — `(1, 50, 256)` и `(1, 8, 16)`;
оба используют float32. Десять официальных стилей включены в APK Beta 2.1.
Их манифест фиксирует исходную ревизию и SHA-256 каждого файла.

Файл с идентификатором Silero не содержит этих массивов. Переименование JSON,
смена расширения или преобразование самого идентификатора в массив не переносят
голос в Tera.

## Возможный путь переноса

Для получения похожего тембра можно исследовать подбор стиля Tera по аудио,
синтезированному Silero. Это отдельная оптимизация в пространстве стилей;
качество, сходство и устойчивость нового голоса требуется проверить после подбора.
Из опубликованных материалов Tera не следует наличие готового интерфейса
«аудио → стиль».

Проект `supertonic.embed` подбирает векторы стиля по эталонному WAV, используя
замороженные модели Supertonic 2 и функцию потерь WavLM. Он рассчитан на CUDA.
Его загрузчик требует `text_encoder`, `duration_predictor`, `vector_estimator`
и `vocoder`, преобразуемые через `onnx2torch`.

Это пока не готовый инструмент для Tera: её опубликованный teacher sampler
содержит верхнеуровневый оператор ONNX `Loop`, а реестр преобразований
`onnx2torch` не содержит конвертера этого оператора. Прежде чем запускать подбор,
нужно адаптировать sampler или реализовать его эквивалент с поддержкой градиентов,
проверить эквивалентность синтеза и лишь затем подбирать новые стили.

В текущем окружении CUDA недоступна. Подбор стилей не запускался, новые
«голоса Silero для Tera» не создавались. Этот эксперимент не нужен для работы
десяти официальных голосов Tera и не задерживает их выпуск.
