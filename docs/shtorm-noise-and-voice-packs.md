# Shtorm: шум и скачивание голосов · Beta225

## Замеры и границы выводов

По жалобе пользователя на гул на всех голосах сгенерированы 12 образцов на OnePlus CPH2745: Alba/Marius/Антон × fast/slow × 1/2 flow steps. Использованы библиотеки из установленного Beta224, CPU FP32 2 потока, temperature0.3, seed42, 24кГц mono; отдельный беззвучный app_process, настройки приложения не менялись. Затем через настоящий TTS-путь приложения сохранены три синтетические фразы Alba в текущем slow/2. Проигрывания не было.

Локальные результаты: `../listening/shtorm-noise-check/` (от корня репозитория). `analysis.json`: классификация тихих окон по энергии300–4000Гц, нижний квинтиль; это оценка тихих участков, **не лабораторный SNR** и не гарантия отсутствия слышимых артефактов во время слов. Отношение активной речи к тихим участкам сырых образцов≈47–56дБ. Выраженная постоянная линия50/100Гц не подтверждена. На трёх выходах самого приложения тихие окна≈−77/−63/−61dBFS, речь≈−18/−17/−17dBFS. Причина слышимого пользователем гула пока не доказана; остаточная окраска нейрокодека — предположение.

Обычные фильтры проверены на **копиях**, настройки/продакшен-звук не изменены:

- дополнительный Butterworth high-pass100Гц: тихие окна−1.0…−2.5дБ, активная речь−0.5…−0.7дБ; затрагивает низкие гармоники голоса;
- FFT denoise `afftdn nr8 nf−50 tn1 gs10`: тихие окна−0.3…−4.4дБ; задержка600samples компенсирована, конец предварительно дополнен, длина сохранена;
- мягкий expander/gate: тихие окна−0.3…−5.1дБ, активная речь по выбранным окнам практически неизменна; не убирает окраску во время слов.

Таким образом, фильтры дают частичное подавление тихого остатка, но исчезновение именно жалобы пользователя не подтверждено слухом. Узкий notch50/100Гц без выявленной линии не добавляли. Уже существующий общий high-pass70Гц по умолчанию включён. Настройку очистки не усиливать вслепую.

Сравнен форк `9208499-ship-it/teratts-android`, branch teratts, снимок6ноября2026: `rust/src/pocket.rs` использует тот же 24кГц Mimi, stateful chunks15frames и flow steps; в `rust/src/denoise.rs` есть отдельный DPDFNet2. Пользователь прямо сказал: его уже пробовали, он не помогает и не нужен. DPDFNet **не интегрирован, не включён, не добавлен в скачивание приложения**.

## Голосовые пакеты

Кнопка **«Скачать пак голосов»** находится в блоке выбранной модели, под параметрами её пакета и перед импортом своего голоса. Всегда видна, при готовом пакете показывает состояние установки. В списке выбора только установленные голоса, скачивание из селектора/preview убрано. Для Shtorm кнопка скачивает7основных и12дополнительных MP3; для Tera — её библиотеку стилей; для Silero/Kokoro голоса входят в общие веса модели. Импорт Tera показывается только у Tera (старый `isTeraModel` означал все русские модели и ошибочно показывал его также у Shtorm/Silero).

12 WAV из TeraWav относятся к **Shtorm**, не TeraTTS. Пользователь подтвердил: **все12 мужские**. Это записано в манифесте и таблице ролей, пол показан в главном списке. Для17дополнительных Silero пользователь хочет сам прослушать и сообщить пол; автоматическая разметка по частоте **не применяется**, пока остаётся «пол не задан». Эти неразмеченные голоса не назначаются автоматически по полу; ручной выбор возможен. Основные5 Silero и7 Shtorm сохранили известную разметку, пользовательские overrides приоритетны.
