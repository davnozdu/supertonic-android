# MyTTS 5.0 Beta 3: расход ресурсов

4 октября 2026 года. Подписанный ARM64 APK `v5.0.0-beta3`, versionCode 89,
установлен поверх Beta 2.1 на OnePlus CPH2745 / Android 16.
SHA-256: `5cc6ad4f918d0e2acc6569207798ba2eb3aa7c4cfb655edfd2f802303e6378ad`.
CI, тесты debug/release, проверка JNI и подпись релиза прошли.
Локально прошли 48 проверок JVM, включая длительный обрыв без повторного
запуска неудачной локальной разметки и последующее восстановление облака.

## Исправления

- Tera: выключено активное ожидание рабочих потоков ORT между вычислениями
  четырёх последовательных графов. Сохранены шесть потоков на этом устройстве,
  sampler, веса, шаги и параметры голоса. Другие движки не получают эту настройку.
- Tera освобождает модель после простоя, сохраняя готовый PCM. Кэшированное
  чтение отмечает активность; таймер не выгружает модель во время вычислений.
- Gemma не повторяет неудачную разметку тех же ожидающих абзацев при каждом
  фоновом восстановлении. Новые абзацы сохраняют обычный локальный резерв;
  фоновые повторные запросы обращаются к облакам. В режиме LOCAL некорректные
  роли не порождают бесконечные повторные расчёты.
- Обновление подготовленных ролей меняет версию задачи аудио. Прежняя задача
  прекращает вычислять последующие фразы; текущий нативный вызов не обрывается.

ORT описывает активное ожидание как обмен дополнительного расхода CPU/энергии
на задержку запуска работы: [документация потоков](https://onnxruntime.ai/docs/performance/tune-performance/threading.html).

## Сравнение Tera на телефоне

Закрытая диагностическая Activity, синтетический русский текст, ru_f1,
distilled cfg3 / 8step, speed=1.1, gain=2.5. Длительность PCM — 3781 мс.
Каждая конфигурация получила собственные сессии и прогрев перед тремя
измеряемыми повторами. CPU-время взято для всего процесса через
`Process.getElapsedCpuTime()`, а не только для вызывающего Java-потока.

| Активное ожидание | Время генерации, мс | CPU-время процесса, мс |
| --- | --- | --- |
| Включено, повтор 1 | 515 | 3159 |
| Включено, повтор 2 | 498 | 3031 |
| Включено, повтор 3 | 532 | 3305 |
| Выключено, повтор 1 | 616 | 2527 |
| Выключено, повтор 2 | 613 | 2497 |
| Выключено, повтор 3 | 621 | 2433 |

В среднем CPU-время уменьшилось на **21,5%** (3165 → 2486 мс), а время
генерации выросло на **19,7%** (515 → 617 мс). После изменения синтез этого
отрывка всё ещё примерно в шесть раз быстрее его воспроизведения.
Результирующий PCM побайтно совпал у обеих конфигураций во всех повторах.
Это небольшой тест на одном телефоне; расход батареи напрямую не измерялся,
цифры не являются гарантией для всех текстов, sampler и устройств.

## Простой и кэш

- Реальный таймер закрыл Tera через 120074 мс без аудиозапросов.
- PSS приложения с загруженной моделью: 992878 КиБ; после выгрузки:
  265351 КиБ (примерно **970 → 259 МиБ**, разница около 710 МиБ).
  Измерение включает Java, нативные библиотеки и другие компоненты приложения;
  это не размер одних весов модели.
- Готовый WAV/PCM остался в RAM: тот же объект на 294194 байта выдался из
  кэша за 0 мс без повторной загрузки Tera.
- В замере `top` после выгрузки CPU процесса был 0%.
- Автономные проверки ё, «По стенам», «Не раз было», пять WAV-проб,
  инвалидация кэша и выдача PCM при занятой модели прошли.

## Регрессия LLM и Silero

Внесён искусственный сбой облачного запроса ролей. Gemma GPU вызвана один раз;
неполная локальная разметка отклонена. Через 5,7 секунды после завершения
первичной обработки план восстановился из Ollama без очистки кэша.
Все три роли дошли до нативного Silero: автор aidar / speaker 0,
женщина kseniya / 2, мужчина eugene / 3. Отредактированный LLM текст
прошёл синтез с обходом внутреннего акцентора. Некорректная локальная разметка
в этой пробе остаётся ограничением Gemma, безопасный вариант — голос автора.

После диагностики обе группы SharedPreferences совпали с актуальными
резервными копиями; настройка экрана при USB возвращена к 0.
В этих прогонах не обнаружено ошибок интеграции или аварий AndroidRuntime.
Длительное прослушивание Moon+ Reader и расход батареи требуют отдельной
проверки во время обычного использования.
