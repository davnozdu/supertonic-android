# База звуков событий (sound bank)

## Открытые записи BigSoundBank: оценка и параллельная загрузка

`download_bigsoundbank.py` использует Python 3.9+ и curl, без сторонних Python-пакетов.
Сохраняет исходное аудио, карточки страниц, JSON с описанием/автором/лицензией,
`CREDITS.md`, SHA256 и отчёт о размере/скорости. Повторный запуск проверяет
хеши скачанных файлов; повреждённые файлы скачиваются заново. Число потоков 1–8,
по умолчанию 4. Ошибки попадают в отчёт и дают ненулевой exit code.

```sh
# Объём всего каталога по метаданным; аудио не скачивается
python3 tools/sound_bank/download_bigsoundbank.py inventory --out /tmp/bsb
# Пример: 100 подходящих WAV с первых трёх страниц, 4 потока
python3 tools/sound_bank/download_bigsoundbank.py download --out /tmp/bsb-100 --catalog-pages 3 --download-limit 100 --workers 4
# Вся библиотека; продолжение повторным запуском той же команды
python3 tools/sound_bank/download_bigsoundbank.py download --out /tmp/bsb --workers 4
```

`--limit` ограничивает количество карточек для изучения, `--download-limit` —
количество скачиваемых подходящих файлов. Поддерживаются `--format wav|mp3|m4a|flac`
и повторяемый `--url` для отдельных карточек. Не каждый файл доступен во всех
форматах. Аудио скачивается только при явной отметке CC0 на странице. Это
подбор для оценки: происхождение и качество необходимо проверить перед публикацией.
Страницы кэшируются в каталоге результата; для свежего обхода использовать новый каталог.
Одновременные запуски в один каталог не поддерживаются.

Проба 06.11.2026: 100 исходных WAV, 2007624006 байт (2,008 GB / 1,870 GiB),
139,1 мин аудио. Два этапа 94+6 новых файлов: суммарно 18,843 с на аудио
(включая проверку кэша), 26,836 с активного времени с каталогом/метаданными;
эффективно 106,5 MB/s. Все 100 файлов проверены как WAV и сверены с SHA256
квитанций. На трёх контрольных файлах проверены повторный запуск без скачивания
и восстановление испорченного файла. Выборка не случайная; полный объём каталога
из неё достоверно не выводится. Данные: `../../../listening/bigsoundbank-100/`
относительно этой папки, итог `benchmark-100.json`.

Лицензии могут публиковаться отдельной страницей, аудио — подкачиваться отдельно.
Для CC0 локальная копия лицензии не обязательна; собранные сведения сохраняются
для учёта. Для будущих CC BY нужна явная доступная ссылка на все обязательные
сведения об авторстве и условиях. Этот скрипт не меняет Android-приложение и
не публикует/не подключает скачанное к действующему банку.

Готовые клипы для «Звуков событий»: один клип на вид действия, 8 секунд, AAC 96 кбит/с, 44 100 Гц, стерео,
−14 LUFS — ровно тот формат, который приложение делает само (`AmbienceBook.EVENT_SECONDS = 8f`, `AacFile`).

Фон локаций сюда не входит: он делается на телефоне, по 30 секунд и в нескольких вариантах на место.

## Файлы

    sounds.json   список звуков: ключ вида, русская подсказка, английский промпт, seed, длительность
    pack.py       сборка папки pack/: клипы + manifest.json + sounds.db (SQLite с поиском по описанию)
    pack/         готовая база (после сборки): <вид>.m4a, manifest.json, sounds.db

## Как делается клип

Модель — та же, что в приложении: Stable Audio 3 Small SFX (`sa_sm-sfx`, DiT w8a8) и декодер SAME-S,
8 шагов сэмплера, seed из списка (по ключу вида, поэтому клип воспроизводим).

    python3 sa3/optimized/tflite/scripts/sa3_tflite.py --dit sm-sfx --decoder same-s --precision w8a8 \
        --seconds 8 --steps 8 --seed <seed> --threads 5 --prompt "<промпт>" --out <вид>.wav
    ffmpeg -i <вид>.wav -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 96k -ar 44100 -ac 2 <вид>.m4a

## Как это работает на телефоне

1. Пользователь скачивает архив базы («База готовых звуков событий» в разделе «Фоновая музыка»).
2. Приложение проверяет sha256 каждого клипа и кладёт их в `files/sound-bank`, рядом пишет `index.json`.
3. Книга, которой нужен вид действия, копирует клип из базы в свою папку — генерации ноль.
4. Чего в базе нет, создаётся для книги один раз и дописывается в базу: следующий раз этот звук бесплатный.
5. Промпты английские: генератор понимает только английский.

## Добавить звук

Дописать запись в `sounds.json` (ключ, подсказку, промпт), сгенерировать клип командами выше, затем
`python3 tools/sound_bank/pack.py <каталог с m4a>` — manifest и база пересоберутся, версия у архива новая.
