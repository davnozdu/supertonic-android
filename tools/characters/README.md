# Персонажи книги для мультиголосовой озвучки

`book_characters.py` — копия скрипта из репозитория [mytts-books](https://github.com/davnozdu/mytts-books)
(`mytts_book.py`): книга EPUB или FB2 (в том числе `.fb2.zip`) на входе, файл `.mytts-book` на выходе.
Та же логика перенесена в приложение (`app/src/main/java/.../books/prepare/`): кнопка «Подготовить книгу»
на экране «Книги с голосами персонажей» делает всё на телефоне, через выбранное облако (Ollama, Gemini или
DeepSeek). Скрипт нужен для компьютера, для проверки и для образцов в `samples/`.

## Запуск

```sh
python3 -m venv venv
venv/bin/pip install pymorphy3 pymorphy3-dicts-ru beautifulsoup4
OLLAMA_API_KEY=... venv/bin/python book_characters.py process book.epub                    # Ollama Cloud
DEEPSEEK_API_KEY=... venv/bin/python book_characters.py process book.epub --provider deepseek
```

Ключ можно положить в файл `.env` рядом со скриптом (`OLLAMA_API_KEY=...`); скрипт ключ никуда не
записывает и не выводит. Отдельные шаги: `extract → llm → apply → voices → export`
(`book_characters.py <шаг> --help`). Голоса по умолчанию — `voices_silero_cis.json` (Silero CIS, 29 голосов).

## Как это работает

1. **Текст и главы.** EPUB или FB2 читается по оглавлению. Роман делится на главы (все уровни оглавления;
   если их нет — заголовки в тексте «Глава 5», «XII.»; иначе книга целиком), сборник — на рассказы.
   Роман это или сборник, скрипт понимает сам: в сборнике у каждого рассказа свои герои, в романе главные
   герои проходят через многие главы. Сноски в разбор не попадают. Перед разбором текст механически
   приводится к одному виду: любые тире («-», «--», «–») → «—», кавычки → «», без звёздочек, значков сносок и
   невидимых символов. Отпечатки для узнавания книги считаются по исходному тексту.
2. **Кандидаты.** Имена, фамилии, отчества, уменьшительные формы, прозвища, обращения («князь», «леди»,
   «генеральша») и описания говорящего («— спросил черномазый», «— сказала мама»). Формы приводятся к
   именительному падежу (pymorphy3 и частоты самой книги), считаются упоминания и реплики («— сказал князь»,
   «— говорит Лорен», «— бормотала, улыбаясь, баба Катя»), определяется пол. Правила общие для любой книги.
3. **Сопоставление в LLM (с размышлением).** LLM получает список кандидатов с короткими примерами (не всю
   книгу) и решает, какие формы означают одного персонажа. Три независимых ответа: склейка остаётся, только
   если её дали не меньше двух из трёх. Второй запрос проверяет каждую склейку. Всё сомнительное — в «прочие».
4. **Обращения по главам (без размышления).** «Генерал», «князь» или голая фамилия могут означать разных
   людей. LLM получает отрывки из каждой главы, где слово встречается, и отвечает, кто назван в каждом. В главе
   с уверенным большинством (80%; 60%, если основной разбор согласен) обращение за этим человеком; где ответы
   расходятся — «прочие»; глава с одним упоминанием следует соседним, если они решены одинаково. Так «генерал»
   в «Идиоте» — Епанчин в одних главах и Иволгин в других.
5. **Голоса.** Трое главных героев и затем те, кто больше говорит, получают свои голоса по полу; один
   персонаж звучит одним голосом во всех главах. Не говорящие (исторические лица в научно-популярной книге)
   своего голоса не получают.
6. **Файл для MyTTS и отчёт.** Персонажи, формы имён, пол, рекомендованные голоса и отпечатки предложений;
   **текста книги в файле нет.** Рядом — `отчёт.txt`: кто каким голосом, чьё обращение в каких главах, что
   ушло в «прочие» и почему.

## Приложение и скрипт

| | Скрипт (`book_characters.py`) | Приложение (`books/prepare/`) |
|---|---|---|
| Морфология | pymorphy3 | `assets/book_morph_ru.tsv.gz` (имена, обращения, люди, служебные слова из OpenCorpora; `build_book_morph.py`) + окончания фамилий и отчеств + частоты книги |
| LLM | Ollama Cloud или DeepSeek | облако из настроек LLM (Ollama, Gemini, DeepSeek) |
| Голоса | `voice_hint` в файле | раздаются в приложении из выбранных моделей (те же правила: трое главных, затем говорящие) |

Правила разбора (обращения, главы, голосование, проверка склеек, решения по главам) одинаковы.
`build_book_morph.py` пересобирает словарь приложения: `python build_book_morph.py ../../app/src/main/assets/book_morph_ru.tsv.gz`.
