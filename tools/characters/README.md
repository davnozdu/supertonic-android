# Персонажи книги для мультиголосовой озвучки

`book_characters.py` готовит книгу (EPUB) к чтению разными голосами без прогона всей книги через LLM.

1. **extract** — локально, за секунды: находит имена, фамилии, отчества, уменьшительные формы, прозвища
   и обращения («князь», «генеральша»), приводит формы к именительному падежу (pymorphy3), считает
   упоминания, реплики в ремарках диалогов («— сказал князь»), род, соседей по абзацам, берёт примеры.
   Роман или сборник рассказов определяется сам: в сборнике у каждого раздела оглавления свои персонажи
   и свой короткий запрос.
2. **llm** — отправляет запросы в Ollama Cloud (по одному, без размышления): LLM даёт каждому персонажу
   идентификатор и относит к нему все кандидаты; нераспознанное — в `other`.
3. **apply** — проверяет ответ (каждый кандидат ровно один раз, без выдуманных номеров) и пишет `cast.json`.

Правила общие для любой книги: морфология и статистика самой книги (как часто слово пишется со строчной
и с заглавной), без списков имён под конкретное произведение.

## Установка

```sh
python3 -m venv venv
venv/bin/pip install pymorphy3 pymorphy3-dicts-ru beautifulsoup4
```

## Запуск

```sh
venv/bin/python book_characters.py extract book.epub -o out/book
OLLAMA_API_KEY=... venv/bin/python book_characters.py llm out/book      # модель deepseek-v4.1-flash
venv/bin/python book_characters.py apply out/book
```

`llm` пропускает разделы, на которые ответ уже есть (`--redo` — спросить заново), `--think` — с
размышлением (в 5–10 раз дольше), `--parallel N` — одновременных запросов (по умолчанию 1). Ответы лежат в `out/book/answers/`,
их можно поправить вручную и снова выполнить `apply`. `--scope book|section` задаёт роман или сборник вручную.

## Файлы

- `candidates.json` — кандидаты: `id` (`c12`, в сборнике `s3c12`), форма в именительном (`key`),
  как написано в книге (`forms`), упоминания, реплики, род, разделы, примеры.
- `llm_request.json`, `llm_prompt_*.txt` — запросы к LLM (по одному на книгу или на рассказ).
- `cast.json` — результат: `sections[].cast` указывает набор персонажей раздела; в `casts[]`
  персонажи (`id`, `name`, `gender`, все формы), `other` (читаются голосом автора или общим голосом
  прочих), `alias_index` (форма → персонаж), `ambiguous` (форма у нескольких персонажей — решать по
  контексту, без контекста — голос прочих). Рассказчик — `author`.
- `book_index.json` — отпечаток абзаца (первые 80 букв без регистра, ё, ударений и знаков, sha1[:12]) →
  раздел. Читалка присылает текст абзацами: по отпечатку MyTTS узнаёт книгу и раздел на лету и включает
  набор голосов этого раздела.

## Проверено (8 октября 2026)

- «Идиот» (Достоевский): роман, 4 раздела, 4577 абзацев, 200 кандидатов, извлечение 1,8 с.
- «Ночной взгляд» (Бобылёва): определён как сборник, 20 рассказов, 163 кандидата, 20 запросов до 6 тыс.
  знаков; DeepSeek v4.1 Flash с размышлением: 117 персонажей, 16 в «прочих», 0 нарушений формата.
  Ошибки LLM возможны (лишняя форма у персонажа, выдуманное полное имя) — их видно в отчёте `apply`.
